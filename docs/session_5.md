Verification (WS-8) surfaced two real bugs, both fixed:

- **The blocked-task coral ring never rendered.** Root cause: a CSS cascade trap — custom classes in `@layer utilities` are emitted AFTER Tailwind's generated utilities, so the arbitrary `shadow-[…]` utility paired with `.orb-card` silently lost. Fixed with a dedicated `.orb-task-blocked` class declared after `.orb-card`; the rule is now documented in AGENTS/CLAUDE so it can't bite again.
- **Dialogs shipped legacy overrides** (`rounded-3xl`, `max-w-md` per dialog) that beat the base panel style — computed 512px/radius-24 vs the reference's measured 500px/radius-20. Normalized: the base `DialogContent` carries `sm:max-w-[500px] rounded-[20px]` and every consumer override was removed.
